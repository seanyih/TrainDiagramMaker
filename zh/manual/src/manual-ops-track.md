「路線資料」頁面下方的**軌道配置**，用來設定每個車站、每個站間有幾條軌道，以及列車在那裡能不能**交會**或**追越**：

* **交會**：對向的兩班列車（一班順行、一班逆行）錯身而過。
* **追越**：同方向的兩班列車，後面的列車超過前面的列車。

沒有設定時，全線都是「四線」，也就是不設任何限制。

如果你只需要「作圖」，**完全不需要設定**任何的軌道配置。這些資料僅當抵達時刻缺失、列車通過時間缺失時，需要程式「推論實際時刻」時才會使用。

!!! info ""
    左側的軌道配置圖**僅供參考**。程式計算時只會使用右側選單與勾選框的內容，圖片不影響計算。因此若軌道配置與實際不符，不會影響功能使用。

## 表格

表格由上到下依照路線的順序，車站與站間交錯排列。每一列的右側可以設定：

1. **下拉選單**：軌道數，可選單線、複線、三線、四線。四線以上不受到任何限制，視同四線計算。但是我們建議您將四線以上的鐵道，拆分成多個運行系統分別作圖，圖面會較整潔。
2. **勾選框**：只有選擇複線或三線時才會出現，設定順行、逆行列車在這裡能不能追越。三線**至少要勾選一個方向** (不可能三線但完全不能追越)，取消最後一個勾選時會被自動勾回。

站間的列另外可以填入**最高速度**（km/h）。填完後，右邊會立刻顯示以最高速度跑完這個站間的**最短運轉時間**（例如 `2m32s`，由上下兩站的里程計算；修改里程時也會跟著更新）。

* 不可填 0、負數或非數字，填入時該格會變成紅底，且不會被採用。
* 填入小於 10 的數字時，右下角會出現黃色警告「您填入的時速過低，請確認是否正確。」，但仍會採用。
* 留白代表未設定。

修改後，左側的配置圖會立刻更新。圖中的箭頭是列車行駛的方向：向下為順行、向上為逆行；淺藍色為車站，深藍色為站間。

站名與里程請在上方的路線表格中修改。

## 快速套用

表格上方的按鈕可以一次設定整條路線。**套用後會覆蓋所有車站與站間的設定**，之後仍可以再個別修改。

| 按鈕  | 車站            | 站間            | 適用              |
| --- | ------------- | ------------- | --------------- |
| 單線  | 複線 + 順行、逆行可追越 | 單線            | 單線鐵路，每站都可以交會、追越 |
| 雙線  | 複線 + 順行、逆行可追越 | 複線            | 一般的複線鐵路         |
| 雙單線 | 複線 + 順行、逆行可追越 | 複線 + 順行、逆行可追越 | 兩條軌道都可以雙向行駛的路線  |
| 不設限 | 四線            | 四線            | 不設任何限制（預設）      |

## 全線最高速度

快速套用按鈕下方的「**全線最高速度**」，填完後會直接填入下方**所有站間**的最高速度，之後仍可以再個別修改。

如果不需要最高速度，勾選旁邊的「**停用**」：所有站間的最高速度會被清空，表格中也不再顯示最高速度與最短運轉時間。取消勾選後會重新顯示（需要重新填入）。

全線最高速度與「停用」的狀態，會和軌道配置一起存在路線 JSON 中。

快速套用按鈕只會改變軌道數與追越設定，不會改變最高速度。

## 存檔

軌道配置和路線資料存在**同一個 JSON 檔案**中（「匯出JSON」的路線資料，以及「匯出全部」），沒有獨立的檔案，格式請見[路線資料檔案格式(json)](manual-dev-route-json.html#軌道配置)。

* 路線 CSV 不包含軌道配置。匯入路線 CSV 時，軌道配置會重設為預設值。
* 匯入沒有軌道配置的舊路線 JSON 時，全線視為「四線」（不設限）。
