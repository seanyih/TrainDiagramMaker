02

簡單

不用學新的軟體，也不用準備完美的資料。

  • 手動輸入或 Excel支援直接在網頁輸入，也可以用 Excel 整理後匯入。
  • 必填資料只有三樣站名、里程、時刻。
  • 不需要精確的時刻表旅客時刻表就夠了。
  • 直觀的 UI 設計表格輸入，所見即所得。
  • 完整的官方操作手冊從資料格式到每個功能都有說明。閱讀手冊

03

快速

從時刻表到成品，不必等待。

  • 不必安裝、不必更新、不連伺服器基於網頁的程式，所有計算都在您的電腦上完成。
  • 即時輸出借助現代的網頁渲染，即時看到結果。
  • 幾乎所有參數都可調整快速畫出您想要的樣子。
  • 印刷模式直接產生 PDF 檔，從時刻表到書籍只要 30 秒。
  • 相容 OuDia / OuDiaSecond直接匯入即可開始使用，也能再匯出回 .oud 檔。
  • 運行型態平日和假日班表不同？直接複製一版，快速決定哪些車哪些天開。
  • 疊圖重疊的路段要畫兩次？快速把資料複製到另一條路線上。
  • 單一檔案匯入、匯出只需一個檔案，從路線到繪製設定全包，快速儲存與分享。

04

現代化

向量輸出，加上自動化的計算。

  • 向量圖檔AI 能讀、無限放大不失真、可透明背景，支援 PowerPoint、Illustrator 等軟體。
  • OuDia 樣式以前的設計，也能用現代的格式輸出。
  • 有結構的 SVG提供 id 與圖層，手動編輯、嵌入網頁都能輕鬆提取單一列車。
  • 列車號不重疊自動計算列車號碼、列車名的標記位置。
  • 自動補全輸入一班列車的時刻，自動套用到其他車次。
  • 待避計算自動算出快車通過的時間，消除旅客時刻表的不準確。
  • 停靠時間計算旅客時刻表精度不夠？程式幫您算。
  • 臨時停車還在手動推算什麼時候到號誌站？程式幫您算。
  • AI 友善網站原生 skills，從整理資料到直接呼叫函式都寫好，交給 AI 就能解放雙手。

USE CASES

您手上有什麼，就從什麼開始。

01

我有時刻表檔案

  1. 把 PDF 的文字複製到 Excel 中，稍加整理
  2. 匯入網站
  3. 輸出圖片

02

我有 API

  1. 下載 skills，請 AI 寫一個程式串接並產生檔案
  2. 整包丟進網站
  3. 輸出圖片

03

我只有旅客時刻表 / 我的時間不準

  1. 照樣整理成檔案，能寫多少寫多少
  2. 提供一些額外資訊，例如軌道配置、最高速限
  3. 程式根據您的資料，還原可能的運轉時刻表
  4. 輸出自動消去衝突的時刻表

04

我想列印 / 出一本運行圖

  1. 整理您的時刻表檔案，輸入到網站
  2. 選擇印刷模式：印刷大小、方向、出血、排版位置、頁碼和其他資料
  3. 選取比例尺：每分鐘、每公里多少 mm
  4. 輸出，得到一整包 PDF 檔案

05

我是架空鐵道創作者

  1. 設定軌道配置，也可以設定跨線列車
  2. 時刻表做完後，用程式自動算出通過時刻
  3. 也可以讓程式自動搜尋衝突的地方並回報，再手動調整

06

我是 OuDia / OuDiaSecond 用戶

  1. 已有的 OuDia 檔案可以直接匯入
  2. 填寫適當資訊後，用求解器計算待避時間
  3. 匯出 OuDia 樣式的向量圖檔，列車號不再重疊
  4. 也可以再次匯出成 OuDia 檔案

部分功能不互通，匯入 / 匯出後會遺失這些資訊。
