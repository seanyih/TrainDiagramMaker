!!! info ""
    以下「列」指橫列(row)、「行」指直行(column)。

時刻表可以用 .csv 檔匯入，建議您使用 Excel 製作。

!!! info ""
    時刻表**分成順行、逆行兩個檔案**。順行的車站順序和路線資料相同；逆行的車站順序和路線資料**相反**，也就是逆行檔案的第一個時刻，是路線資料最後一站的時刻。

## 格式一：只有發車時刻

**一班車佔一行**，由左到右排列。設路線共有 N 個車站：

| 第幾列 | 內容 | 必填 |
|---|---|---|
| 第 1 列 | 車次（例如 2721C、123） | 是（內容可留白） |
| 第 2 列 ~ 第 N+1 列 | 列車在每個車站的發車時刻 | 是 |
| 第 N+2 列 | 列車名（例如 普通、自強） | 否 |
| 第 N+3 列 | 線條顏色，填 1 ~ 10 的數字 | 否 |

* **未經過該站或通過時刻不詳，請留白。**
* 已知通過時刻者，請填入通過時刻。
* 終點站請填入抵達時刻。
* 時刻表內請**不要加上站名**，只留純粹的時刻即可。
* 線條顏色對應基本設定中的「列車顏色集」，留白則使用顏色 1，詳情請見[此頁](manual-ops-setting.html#列車顏色集設定)。
* 匯入時，請用匯入/匯出頁面中「**發車時刻**」那一行的匯入按鈕。到站時刻會在輸出圖片時，依照「預設停站時間」自動算出。

以一條 5 個車站的路線、3 班車為例，在 Excel 中會是這樣：

|   | A | B | C |
|---|---|---|---|
| **1** | 2721C | 2723C | 2725C |
| **2** | 528 | 606 | 637 |
| **3** | 531 | 609 | 640 |
| **4** | 537 |  | 646 |
| **5** | 539 | 617 | 648 |
| **6** | 542 | 620 | 651 |
| **7** | 普通 | 快速 | 普通 |
| **8** | 1 | 5 | 1 |

上表中，2723C 不停第 3 站，所以第 4 列留白。

## 格式二：同時有到站和發車時刻

**一班車佔兩行**：左邊是到站時刻，右邊是發車時刻。車次、列車名、顏色寫在左邊那一行，右邊那一行留白。

|   | A | B | C | D |
|---|---|---|---|---|
| **1** | 2721C |  | 2723C |  |
| **2** |  | 528 |  | 606 |
| **3** | 530 | 531 | 608 | 609 |
| **4** | 536 | 537 |  |  |
| **5** | 538 | 539 | 616 | 617 |
| **6** | 542 | 542 | 620 | 620 |
| **7** | 普通 |  | 快速 |  |
| **8** | 1 |  | 5 |  |

* 起點站沒有到站時刻，留白即可。
* **終點站的發車時刻請填入抵達時刻**。只填到站時刻的話，最後一段線不會畫出來。
* 通過的車站，到站和發車都填入通過時刻（相當於停車 0 秒）。
* 匯入時，請用匯入/匯出頁面中「**到發時刻**」那一行的匯入按鈕。

!!! warning "使用舊版檔案的使用者"
    舊版網站的格式是把車次、列車名、顏色放在最上面三列。現在只有**車次在第一列**，列車名和顏色移到了**最後兩列**。舊檔案請先調整後再匯入。

## 時刻輸入細則

!!! success "時刻輸入細則"
    1. 時刻的輸入舉例如下：
        * 早上 9:35 可接受的輸入為 0935 或 935
        * 下午 1:28 可接受的輸入為 1328
    2. 若時刻帶秒數，例如下午 1:28:30，可直接輸入 132830。
    3. 小時前面的 0 可省略，分及秒則不可。例如早上 9:05 可寫成 905 或 0905，但<span style="color:red">**不可寫成 095 或 95**</span>。
    4. 00 秒可寫可不寫：例如 21:09:00 可寫成 2109 或 210900。
    5. **不支援 28、30 小時制**，跨夜的班次直接寫時刻即可（例如凌晨 0:15 寫成 0015）。

格式不正確的時刻，匯入時會被當作空白。

## 存檔

存檔時，存檔類型請選擇「**CSV(逗號分隔)**」，再儲存至您要的位置即可。

!!! danger ""
    若您有使用**漢字、日文、韓文**等（例如列車名），存檔請參閱[這裡](manual-format-excel-encoding.html)。
