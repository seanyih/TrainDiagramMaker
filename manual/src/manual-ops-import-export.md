「匯入/匯出」分頁可以把準備好的檔案一次填進網站，也可以把目前的進度存成檔案，下次再匯入繼續使用。

每一行的**左邊是匯出**：填入檔名（選填，不填會使用預設檔名），再按下匯出按鈕，檔案就會下載到您的電腦。

每一行的**右邊是匯入**：先按「選擇檔案」選取檔案，再按下**匯入**。成功或失敗時，右下角都會出現提示。

頁面上方是常用的路線、時刻表與全部資料。設定、疊圖、OuDia 檔案在下方的「**更多**」，點一下展開。

## 可以匯入、匯出哪些資料

| 項目           | 匯出格式       | 匯入         | 內容                             |
| ------------ | ---------- | ---------- | ------------------------------ |
| 路線資料         | CSV、JSON   | CSV、JSON   | 站名、里程、停站時間、別名；JSON 另含軌道配置、線路拓樸 |
| 順行列車資料（發車時刻） | CSV        | CSV、JSON   | 順行時刻表，只有發車時刻                   |
| 順行列車資料（到發時刻） | CSV、JSON   | CSV、JSON   | 順行時刻表，到站和發車時刻                  |
| 逆行列車資料（發車時刻） | CSV        | CSV、JSON   | 逆行時刻表，只有發車時刻                   |
| 逆行列車資料（到發時刻） | CSV、JSON   | CSV、JSON   | 逆行時刻表，到站和發車時刻                  |
| 設定           | JSON       | JSON       | 基本設定頁面中所有的設定                   |
| 全部資料         | JSON       | JSON       | 以上全部：路線、順逆行時刻表、設定              |
| OuDia 檔案     | .oud、.oud2 | .oud、.oud2 | 路線、一份ダイヤ的順逆行時刻表、種別的線條樣式        |

### CSV 和 JSON 有什麼不同？

* **CSV**：可以用 Excel 或記事本打開、編輯。適合自己整理資料時使用。格式請見[路線資料檔案格式(csv)](manual-format-route-csv.html)和[時刻表資料檔案格式(csv)](manual-format-timetable-csv.html)。
* **JSON**：給程式讀的格式，一般不需要打開它。適合存檔、分享給別人，或從其他網站、程式取得資料。格式請見「開發指南」。

網站會依照**副檔名**判斷檔案種類：`.json` 結尾的檔案當作 JSON，其他都當作 CSV。

## 匯入路線資料

匯入路線資料後，網站會自動：

1. 把資料填進「路線資料」頁面
2. 檢查里程
3. 依照新的車站建立時刻表

!!! info ""
    請**先匯入路線資料，再匯入時刻表**。時刻表檔案裡沒有站名，網站是依照路線資料的車站順序來對應時刻的。

## 匯入時刻表

時刻表分成順行和逆行，請在對應的那一行匯入。

* 只有發車時刻的 CSV，請用「**發車時刻**」那一行的匯入按鈕。
* 同時有到站和發車時刻的 CSV，請用「**到發時刻**」那一行的匯入按鈕。
* JSON 檔案用哪一行的匯入按鈕都可以，只要方向（順行/逆行）對就好。

最上面的「**匯入列車資料時**」選單，決定匯入時如何處理已經有的列車：

| 選項            | 效果                                 |
| ------------- | ---------------------------------- |
| 取代該方向現有列車（預設） | 刪掉該方向原本的列車，換成檔案中的列車                |
| 附加至該方向現有列車之後  | 保留原本的列車，把檔案中的列車加在後面（原本完全空白的列車會被移除） |

「附加」適合把一份很長的時刻表分成好幾個檔案，分批匯入。

## 匯入/匯出設定

把「基本設定」頁面中所有的設定（顏色、比例、文字大小等）存成一個檔案。如果您有固定喜歡的樣式，可以存起來，下次做別的路線時直接匯入。

## 匯入/匯出全部資料

**最推薦的存檔方式。** 一個檔案就包含路線、順逆行時刻表和所有設定。

* 按下**匯出全部**，就能保存目前所有的進度。
* 下次回來時，選取這個檔案並按下**匯入全部**，就會回到存檔時的狀態。
* 匯入全部資料時，時刻表一律是「取代」，不看「匯入列車資料時」選單。
* 如果檔案有問題無法讀取，網站不會做任何變更，原本的資料都會保留。

!!! warning ""
    網站不會自動存檔。關閉網頁或重新整理前，記得先匯出全部資料。

## 匯入 OuDia 檔案

OuDia是日本老牌的運行圖繪製器，基於C語言寫成。很多以前的時刻表、前人繪製的運行圖都使用OuDia檔案。我們的網站提供直接讀入 OuDia（`.oud`）與 OuDiaSecond（`.oud2`）路線檔的功能。

1. 按「選擇檔案」選取 `.oud` 或 `.oud2` 檔。
2. 檔案中有多份ダイヤ（例如平日、休日）時，在「ダイヤ」選單選擇要匯入哪一份。
3. 按**匯入**。路線、順逆行時刻表都會被取代。

匯入的內容：

* **車站**：站名。OuDia 的「一般駅」設為[次要車站](manual-ops-topology.html#次要車站)，「主要駅」為一般的車站。
* **里程**：**OuDia 檔案沒有里程**，網站依 OuDia 的方式（兩站間最快的列車的運轉時間）推算，**1 分鐘 = 1 公里**，畫出來的站距和 OuDia 相同。若要用真正的里程，請到「路線資料」修改。
* **列車**：下り為順行、上り為逆行。車次為列車番號；列車名為「列車名 號數」，沒有列車名時用種別名稱。通過時有時刻的站成為通過時刻；只有發車時刻的中途停車站，到站時刻留白。
* **種別**：依線條顏色、線型、粗細分組，放到列車顏色 1~10，並設定[依顏色的線寬、線型](manual-ops-setting.html#線條)。一點鎖線改為虛線。超過 10 種時，多出的種別使用顏色最接近的那一組。
* **其他**：背景色、軸色（[OuDia 樣式](manual-ops-setting.html#oudia-樣式)使用）、圖的起點時刻（顯示 24 小時）。

!!! note ""
    列車在中途「運行なし」或「經由なし」（例如經由分岐線）時，網站的列車線必須連續，所以這班車會在該處拆成兩班（車次相同）。番線、駅作業、運用等 OuDiaSecond 的資料不會匯入。

## 匯出 OuDia 檔案

把目前的路線與順逆行時刻表存成 OuDia 可以開啟的檔案。填入檔名後按**匯出 .oud**（OuDia）或**匯出 .oud2**（OuDiaSecond）。

* **車站**：[次要車站](manual-ops-topology.html#次要車站)為「一般駅」，其他為「主要駅」。有停車時間的站，時刻表顯示著發兩行。
* **里程**：`.oud2` 會記下每個站間的距離（OuDiaSecond 的「駅間距離」，1 公里 = 1 分），在 OuDiaSecond 中的站距與本網站相同，再匯入本網站時里程也不變。`.oud` 沒有這個欄位，OuDia 會依運轉時間重新排列站距。
* **種別**：每個列車顏色成為一個種別，線條顏色、線型、粗細照「線條」中依顏色的設定。同一顏色的列車列車名都相同時，用它當種別名；否則種別名為「顏色1」等，列車名照填（「はやて 3号」會拆成列車名與號數）。
* **列車**：通過時刻寫成「通過」並附時刻；沒有時刻的中間車站為「通過」。

!!! note ""
    `.oud` 使用 Shift_JIS 編碼，無法表示部分繁體中文字。這些字會變成「?」，並跳出黃色提醒，此時請改用 `.oud2`。單一列車的線條樣式、釘選、軌道配置、線路拓樸不會匯出。

## 疊圖

兩條路線共用一段軌道時（例如內灣線的新竹–北新竹段與縱貫線共用），可以把一條路線上這一段的列車「疊」到另一條路線上，不必重新畫。

1. 打開已經畫好的路線（例如縱貫線，已[還原通過時間](manual-ops-passing-time.html)並採用），在「疊圖」選擇**從**、**到**兩站，按**匯出區段**。檔案包含這一段中每一班車在每一站的時刻：停靠站照時刻表，通過的車站則是圖上列車線的時刻，**精確到秒**，不受「通過時刻的最小單位」限制。
2. 打開另一條路線（例如內灣線），選取剛才的檔案，按**疊加**。

疊加時：

* **車站以站名對應**。本路線沒有的車站會略過；如果它是本路線[線路拓樸](manual-ops-topology.html)中分岐上的車站，會順便填成列車的始發、終點（列車原本沒有設定時）。
* **列車以車次對應**，同方向、同車次的列車視為同一班，把時刻合併進去，**不會重複**；沒有車次的列車，以「同一站、同一時刻」對應。找不到的列車才新增。重複疊加同一個檔案不會改變任何東西。
* 「**已有時刻的站**」選單：以疊圖為準（預設，覆蓋本路線原有的時刻）或保留現有時刻。疊圖中空白的到站時刻（來源也不知道）不會覆蓋本路線的時刻。
* 疊加的時刻會**釘選**：[還原通過時間](manual-ops-passing-time.html#釘選的時刻)不會移動它們。時刻表中釘選的格子有底線，可在「車次細項」中解除釘選。

疊圖檔案的格式見[時刻表資料格式(json)](manual-dev-timetable-json.html#疊圖檔案)。
