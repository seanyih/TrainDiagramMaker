「匯入/匯出」分頁可以把準備好的檔案一次填進網站，也可以把目前的進度存成檔案，下次再匯入繼續使用。



每一行的**左邊是匯出**：填入檔名（選填，不填會使用預設檔名），再按下匯出按鈕，檔案就會下載到您的電腦。

每一行的**右邊是匯入**：先按「選擇檔案」選取檔案，再按下**匯入**。成功或失敗時，右下角都會出現提示。

## 可以匯入、匯出哪些資料

| 項目           | 匯出格式     | 匯入       | 內容                |
| ------------ | -------- | -------- | ----------------- |
| 路線資料         | CSV、JSON | CSV、JSON | 站名、里程、停站時間、別名；JSON 另含軌道配置 |
| 順行列車資料（發車時刻） | CSV      | CSV、JSON | 順行時刻表，只有發車時刻      |
| 順行列車資料（到發時刻） | CSV、JSON | CSV、JSON | 順行時刻表，到站和發車時刻     |
| 逆行列車資料（發車時刻） | CSV      | CSV、JSON | 逆行時刻表，只有發車時刻      |
| 逆行列車資料（到發時刻） | CSV、JSON | CSV、JSON | 逆行時刻表，到站和發車時刻     |
| 設定           | JSON     | JSON     | 基本設定頁面中所有的設定      |
| 全部資料         | JSON     | JSON     | 以上全部：路線、順逆行時刻表、設定 |

### CSV 和 JSON 有什麼不同？

* **CSV**：可以用 Excel 或記事本打開、編輯。適合自己整理資料時使用。格式請見[路線資料檔案格式(csv)](manual-format-route-csv.html)和[時刻表資料檔案格式(csv)](manual-format-timetable-csv.html)。
* **JSON**：給程式讀的格式，一般不需要打開它。適合存檔、分享給別人，或從其他網站、程式取得資料。格式請見「開發指南」。

網站會依照**副檔名**判斷檔案種類：`.json` 結尾的檔案當作 JSON，其他都當作 CSV。

## 匯入路線資料

匯入路線資料後，網站會自動：

1. 把資料填進「路線資料」頁面
2. 檢查里程（有問題的格子會變成紅底）
3. 依照新的車站建立時刻表

!!! info ""
    請**先匯入路線資料，再匯入時刻表**。時刻表檔案裡沒有站名，網站是依照路線資料的車站順序來對應時刻的。

## 匯入時刻表

時刻表分成順行和逆行，請在對應的那一行匯入。

* 只有發車時刻的 CSV，請用「**發車時刻**」那一行的匯入按鈕。
* 同時有到站和發車時刻的 CSV，請用「**到發時刻**」那一行的匯入按鈕。
* JSON 檔案用哪一行的匯入按鈕都可以，只要方向（順行/逆行）對就好。

最上面的「**匯入列車資料時**」選單，決定匯入時如何處理已經有的列車：

| 選項            | 效果                                 |
| ------------- | ---------------------------------- |
| 取代該方向現有列車（預設） | 刪掉該方向原本的列車，換成檔案中的列車                |
| 附加至該方向現有列車之後  | 保留原本的列車，把檔案中的列車加在後面（原本完全空白的列車會被移除） |

「附加」適合把一份很長的時刻表分成好幾個檔案，分批匯入。

## 匯入/匯出設定

把「基本設定」頁面中所有的設定（顏色、比例、文字大小等）存成一個檔案。如果您有固定喜歡的樣式，可以存起來，下次做別的路線時直接匯入。

如果是舊版網站匯出的設定檔，缺少的項目會自動使用預設值，不會出錯。

## 匯入/匯出全部資料

**最推薦的存檔方式。** 一個檔案就包含路線、順逆行時刻表和所有設定。

* 按下**匯出全部**，就能保存目前所有的進度。
* 下次回來時，選取這個檔案並按下**匯入全部**，就會回到存檔時的狀態。
* 匯入全部資料時，時刻表一律是「取代」，不看「匯入列車資料時」選單。
* 如果檔案有問題無法讀取，網站不會做任何變更，原本的資料都會保留。

!!! warning ""
    網站不會自動存檔。關閉網頁或重新整理前，記得先匯出全部資料。
