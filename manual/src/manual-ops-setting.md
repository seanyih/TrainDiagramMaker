基本設定分成三大部分，**點擊標題即可展開**。所有設定都有預設值，不調整也可以直接輸出圖片。設定改變後，請再按一次「輸出結果」，圖片才會更新。

## 列車顏色集設定

本網站提供 10 種顏色，用來標示運行圖上不同的車種、列車種類等等。這 10 個預設顏色可以在這裡改成您喜歡的顏色。

每班車要用哪一個顏色，在「時刻表」頁面選擇，詳情請見[此頁](manual-ops-timetable.html#列車名與線條顏色)。顏色集一經更改，**時刻表內的顏色也會同步變更**。但是**已經輸出的圖片不會改變**，若您想套用新的顏色，請再輸出一次。

## 自動估計設定

設定頁最上方的「依路線與時刻表自動估計」會依車站數、站距、尖峰每小時班次、列車的時間範圍與站名長度，估計每公里 / 每分鐘的長度、顯示的時間範圍、線寬、次要時間線間隔、各種文字大小、列車號大小與頻率、圖片邊界，並直接填入設定。列車顏色與時間文字格式不變。這是經驗法則，結果可再手動微調。

## 繪圖設定

### 預設停站時間

時刻表中只有發車時刻、沒有到站時刻的車站，網站會用「發車時刻減去預設停站時間」當作到站時刻。預設是 60 秒，您可以根據運輸系統調整，例如地鐵可以短一些、高鐵可以長一些。

### 圖上每公里 / 每分鐘的長度

也就是縱軸 / 橫軸的比例尺。想要圖小一些，可以將兩個數值都調小。

預設值皆為 25 像素，也就是在圖上 45° 的斜線，代表一列平均時速 60 公里的列車，這個比例較適合傳統鐵路。若要製作高速鐵路的運行圖，建議將「圖上每公里的長度」調為 10 像素，此時 45° 的斜線代表平均時速 150 公里的列車。您可以利用以下公式，算出 45° 的斜線代表的平均時速：

**平均時速(公里/小時) = 圖上每分鐘的長度 ÷ 圖上每公里的長度 × 60**

!!! info ""
    以大部分列車的平均速度來設定這個比例，**畫出來的運行圖會比較好讀**。因此可以依照路線的不同調整比例尺。

### 圖上顯示的時間範圍

大部分鐵路系統都不是 24 小時營運。若您想跳過半夜圖上空白的部分，可以在這裡填入想顯示的時段。請用 4 位數字（hhmm）輸入，例如 0500 ~ 2400。

建議以整點為單位裁切。例如第一班車早上 5:30 開出，建議設定 0500 為起始時間而非 0530，這樣看圖的人比較容易讀出時間。

### 圖片邊界

圖表外框到圖片邊緣的距離，上下左右可以分別設定。左邊要放站名、右邊要放站名別名、下面要放時間，所以文字較大或站名較長時，請把對應的邊界調大。

### 背景

選擇背景顏色。勾選「透明」則沒有背景，適合把圖片放進簡報或其他設計中。

### 線條

| 線條    | 說明                                 |
| ----- | ---------------------------------- |
| 車站線   | 每個車站的橫線                            |
| 次要車站線 | [次要車站](manual-ops-topology.html#次要車站)（例如信號場）的橫線，預設為灰色、較細 |
| 整點線   | 每個整點的直線                            |
| 次要時間線 | 整點之間的直線，可以選擇每 1、5、10、15、20、30 分鐘一條 |
| 分鐘時間線 | 沒有時間線的每一分鐘，以點線繪製，每公里一點、由上到下，預設關閉；線寬就是點的直徑 |
| 圖表外框  | 圖表四周的框線，固定為實線，上下左右可以分別設定粗細 |
| 列車線   | 所有列車線的粗細與線型，也可以依顏色分別設定；單一列車的設定見[列車名與線條顏色](manual-ops-timetable.html#列車名與線條顏色) |

每一種線條都可以設定粗細（線寬）和顏色；除了圖表外框，也可以選擇線型：實線（預設）、虛線、點線。

### 列車號

在列車線旁邊標上車次，文字顏色和列車線相同。

* **顯示**：取消勾選就不標車次。
* **字型大小**：車次文字的大小。
* **每隔多少像素標一次**：列車線很長時，每隔這段距離（上下方向）再標一次。數字越大，標得越少。
* **站距小於多少像素不標**：兩站太近時放不下文字，就跳過這一段，改標在下一段。

### 列車號避讓

讓車次文字盡量不要壓到其他列車的線、其他車次，或時間線。

!!! warning ""
    這些設定會增加電腦的負擔。電腦或手機效能較弱時，請盡量放寬設定（例如取消勾選、把間距調小），否則可能畫不出來，甚至讓瀏覽器當掉。

* **啟用避讓**：取消勾選則車次文字可以和其他線、文字重疊。
* **避開整點線 / 避開次要時間線**：勾選後，車次也會避開這些線。次要時間線之間的距離要夠寬（至少 250 像素）才能勾選。
* **與線、文字的最小間距**：車次文字和其他東西之間至少要留多少空間，可填 0 ~ 20。

找不到地方放的車次會被省略。

### 車站文字

* **站名**：顯示在圖的左側，可以設定字型大小、顏色，以及和圖表的距離。
* **站名別名**：顯示在圖的右側，勾選「顯示」才會出現。別名在「路線資料」頁面輸入，詳情請見[此頁](manual-ops-route.html)。
* **次要站名、次要站名別名**：[次要車站](manual-ops-topology.html#次要車站)的站名與別名，可以分開設定（預設為灰色、較小）。別名是否顯示同樣看上面的「顯示」。這兩項沒有預覽。

### 時間文字

圖的下方標示時間的文字。

* **表達方式**：
  * 固定大小 hh:mm：例如 8:00
  * 大小差別 hhmm：小時用大字、分鐘用小字
  * 簡化：整點只標小時、次要時間線只標分鐘
* **小時補 0**：勾選後 8:00 會變成 08:00。
* **與圖表距離**：時間文字和圖表下緣的距離。
* **次要時間線標記**：次要時間線要不要也標時間。次要時間線的間隔大於 10 分鐘時才可使用。
* **字型大小、顏色**：依照選擇的表達方式而不同。

下方的預覽會即時顯示 8:00 ~ 9:00 的樣子。
